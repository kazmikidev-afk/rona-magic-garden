# הגן הקסום של רונה, V2
Discovery studio for age-6/7 challenges with an easy entry level. Hebrew RTL, Android tablet-first, phone support, offline PWA. 22 activity entries across language, math, English and creative labs. No build step. All speech is bundled; no runtime network dependencies other than initial download/update.

See NOTES.md for scope and limitations and AUDIO-V2.md for new speech scripts. Open once online, wait for offline-ready, close old app tabs and reopen after updates. No saved learning history or child accounts. Recording is parent-gated, memory-only, max 15s and deleted on exit/hidden page. Browser permission is separate. No paid services used. Physical Android and native Hebrew listening still required.
