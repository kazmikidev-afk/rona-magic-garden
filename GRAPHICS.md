# Graphics preview 1
Real local WebGL 3D in home, slime, wardrobe and zoo. Free Three.js (MIT license bundled), original code-generated geometry/materials, directional and hemisphere lighting, shadows, glossy slime, camera depth and drag rotation. Approximately 554KB additional bundled JavaScript, no CDN or external models. Stylized 3D, not photorealism or commercial character assets. No activity trimming in this phase.

Existing games, session-only state, voice/mic cleanup and offline behavior remain the source of truth. 2D SVG is retained as fallback if WebGL cannot initialize. Rendering capped to roughly20fps with pixel ratio<=1.6, only one active scene, paused while hidden. Real low-end Android performance still requires a device test. Physical tablet, native Hebrew diction and other previously documented limitations remain.

Current preview still needs independent gameplay/visual/performance review. Scenes are intentionally focused on the four requested high-impact places, not a claim that every activity has been converted to3D.
